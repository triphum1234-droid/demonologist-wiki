# Demonologist Pro Guide

คู่มือ Demonologist ภาษาไทยแบบหน้าเว็บเดียว ใช้เทียบหลักฐานและพฤติกรรมเพื่อช่วยจำกัดรายชื่อผีที่เป็นไปได้

[เปิดตัวแอป](./index.html)

## ความสามารถ

- ดูหลักฐานของผีแต่ละชนิด พร้อมรายละเอียดพฤติกรรม จุดสังเกต และแนวทางรับมือ
- กรองจากหลักฐาน 7 ประเภท: EMF Level 5, ESG, Easel Canvas, Freezing, Spirit Box, Fingerprints และ Ectoplasm
- กรองจากพฤติกรรมของผี และดูการ์ดของผีที่ยังตรงกับตัวกรอง
- ตัวเลือกตัวกรองสลับได้ 3 สถานะ: ยังไม่ระบุ, พบ และไม่พบ
- ระบบทำเครื่องหมายตัวเลือกที่ถูกตัดออกหรือยืนยันได้จากผีที่เหลือโดยอัตโนมัติ
- เปิดคู่มืออุปกรณ์และอ่านคำอธิบายประกอบในหน้าเดียว

## วิธีใช้

1. เปิด `index.html` ด้วยเว็บเบราว์เซอร์
2. เลือกหลักฐานหรือพฤติกรรมจากแถบตัวกรองด้านซ้าย
3. กดตัวเลือกซ้ำเพื่อสลับระหว่าง **พบ**, **ไม่พบ** และ **ยังไม่ระบุ**
4. ดูรายชื่อผีที่ยังเป็นไปได้ แล้วเลือกการ์ดเพื่ออ่านรายละเอียด
5. กด **ล้างตัวกรองทั้งหมด** เพื่อเริ่มคัดกรองใหม่

## ไฟล์ในโปรเจกต์

- `index.html` — ตัวแอป คู่มืออุปกรณ์ และข้อมูลผี
- `README.md` — คำอธิบายโปรเจกต์และวิธีใช้งาน

## การเปิดใช้งาน

หน้าเว็บโหลด React, Babel, Tailwind CSS และฟอนต์จาก CDN ดังนั้นต้องเชื่อมต่ออินเทอร์เน็ตขณะเปิดหน้าเว็บเพื่อให้ส่วนติดต่อแสดงผลได้ครบ
